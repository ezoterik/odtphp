# odtPHP

OdtPHP is a PHP librairy designed to use OpenDocument file as a template for PHP. It's a kind of PHPLib for OpenOffice
document.

http://sourceforge.net/projects/odtphp/

## Requirements and compatibility

PHP 7.1 or later is required. PHP 5.3 through 7.0 are no longer supported. Compatibility has been verified on PHP
7.1.33, 7.4.33, 8.2.34, and 8.4.26 with `E_ALL` enabled.

The native PHP ZIP extension is recommended. The bundled PclZip library remains available and has also been tested on
these versions.
